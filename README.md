## 2. Python Theory: Intro to Python

**Jupyter Notebook Shortcuts:**
- `Shift+Enter` — execute cell and move to next
- `Ctrl+Enter` — execute cell, stay in place
- `a / b` — insert cell above/below
- `dd` — delete cell
- `m / y` — convert to Markdown/code
- `Tab` — autocomplete, `Shift+Tab` — documentation

**Topics covered:**
- String formatting with f-strings
- Dictionaries and lists for JSON structures
- Nested data structures for API payloads
- Functions with type hints and default parameters
- List comprehensions and filtering
- Control flow and error handling
- Lambda functions and sorting
- Working with API response structures

**Notebook:** https://github.com/hyperskill-content/Python_intro/blob/main/notebooks/Python_Intro_Preliminary.ipynb

Build instructions are in the repository's README.md.

## 3. Python Theory: HTTP Requests and Async

**Topics covered:**
- HTTP requests with the requests library
- GET/POST/PUT/DELETE methods
- Query parameters and request bodies
- Response handling (status codes, JSON parsing, headers)
- Sessions and context managers
- Async programming with async/await
- aiohttp for concurrent requests
- asyncio.gather() for parallel execution
- Rate limiting and error handling in async contexts

**Notebook:** https://github.com/hyperskill-content/Python_intro/blob/main/notebooks/HTTP_async.ipynb
